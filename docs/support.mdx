## Documentation

Start with the [quickstart](/quickstart), [provider setup guides](/providers/supported), or [API reference](/api-reference/introduction).

## Bugs and proposals

Open an issue in [IYENTeam/healine](https://github.com/IYENTeam/healine/issues). Include the component, expected behavior, actual behavior, and steps to reproduce. Remove credentials and personal health data from examples.

For security reports, follow [Healine's security policy](https://github.com/IYENTeam/healine/blob/main/SECURITY.md).

## Upstream reference

Healine is based on [Open Wearables](https://github.com/the-momentum/open-wearables). Its [documentation](https://openwearables.io/docs) describes the upstream platform and separately distributed mobile SDKs.
