## Current foundation

Healine reuses the Open Wearables backend, developer portal, provider integrations, and MCP server. The current fork establishes the Healine identity while preserving upstream protocol compatibility.

## Planned work

- Add Polar AccessLink v4 collection alongside the inherited v3 connector.
- Preserve raw responses and improve recovery of delayed data.
- Connect stored observations to Healine state calculation and Calendar output.

These extensions are not implemented yet. Track proposals and implementation in [Healine issues](https://github.com/IYENTeam/healine/issues).
