## Configuration

Add the following to your Cursor MCP settings:

```json
{
  "mcpServers": {
    "healine": {
      "command": "uv",
      "args": [
        "run",
        "--frozen",
        "--directory",
        "/path/to/healine/mcp",
        "start"
      ]
    }
  }
}
```

<Warning>
  Replace `/path/to/healine/mcp` with the actual path to the MCP directory on your system.
</Warning>

<Tip>
  If the server fails to start, you may need to use the full path to `uv` instead of just `"uv"`. You can find it by running:
  ```bash
  which uv
  # e.g. /Users/bart/.local/bin/uv
  ```
  Then replace `"command": "uv"` with the full path, e.g. `"command": "/Users/bart/.local/bin/uv"`.
</Tip>

## Verifying the Connection

After configuring Cursor:

1. Restart Cursor
2. Open the AI chat panel
3. Try asking: "Who can I query health data for?"

If configured correctly, the AI will use the `get_users` tool to fetch available users from your Healine instance.

## Testing with MCPJam

[MCPJam](https://www.mcpjam.com/) is a local inspector for testing MCP servers. It provides a UI to explore tools, test calls, and debug responses.

```bash
npx @mcpjam/inspector@latest
```

Then configure the connection:
- **Command**: `uv`
- **Arguments**: `run --frozen --directory /path/to/healine/mcp start`

## Troubleshooting

### "Invalid API key" error

Ensure your `OPEN_WEARABLES_API_KEY` in `config/.env` is valid. Keys are generated in the API Keys section of the Healine developer portal (Settings tab). The full key is shown only once, right after it is created or rotated - if you no longer have it, rotate the key in the portal and update `config/.env` with the new value.

### "Connection refused" error

Make sure the backend is running at the URL specified in `OPEN_WEARABLES_API_URL`.

For local development:
```bash
# From project root
docker compose up -d
```

### No users found

Make sure `OPEN_WEARABLES_API_URL` in `mcp/config/.env` points to the **API base URL** (e.g. `https://api.openwearables.io` or `http://localhost:8000`), not the URL of your Healine dashboard/frontend. The MCP server calls `GET /api/v1/users` on this URL - if it points to the wrong service, you'll get a 404 ("Resource not found").
