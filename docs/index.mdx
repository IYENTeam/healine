## Wearable data in one place

Healine connects wearable providers to a shared API and developer portal. It includes background synchronization, normalized time series, sleep and workout records, and an MCP server for querying stored data.

Healine is a fork of [Open Wearables](https://github.com/the-momentum/open-wearables), originally developed by Momentum under the MIT license.

## Current scope

The fork currently rebrands the upstream platform. Polar AccessLink v4 collection and the Healine Calendar integration are planned work. The separately published Open Wearables mobile apps and SDKs remain upstream products; their names and protocol identifiers are retained for compatibility.

Source code and issue tracking live in [IYENTeam/healine](https://github.com/IYENTeam/healine).
