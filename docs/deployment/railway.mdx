## Deployment source

This fork does not publish a Healine Railway template. The [upstream Open Wearables template](https://railway.com/deploy/open-wearables-1) targets the upstream application.

To deploy Healine, build from [this repository](https://github.com/IYENTeam/healine). The [Docker guide](/deployment/docker) describes its production images, required configuration, and service commands.

## Services to configure

Use PostgreSQL and Redis alongside the backend, frontend, Celery worker, and Celery beat. Outgoing webhooks also require Svix. Refer to `docker-compose.yml` for each service's command and dependencies.

- Build the backend image with `backend/Dockerfile` and the frontend with `frontend/Dockerfile`.
- Configure database and Redis connectivity for the backend and workers.
- Set `SECRET_KEY`, `ADMIN_EMAIL`, and `ADMIN_PASSWORD` before the backend's first startup.
- Set the frontend's `VITE_API_URL` and the backend's `FRONTEND_URL` and `CORS_ORIGINS` to your deployed service URLs.
- Configure provider credentials in the developer portal and register OAuth callback URLs for your backend domain.

This manual deployment has not been validated for Healine on Railway. Use the local [Docker setup](/deployment/docker) as the starting point.
