## Frequently Asked Questions

### General Questions

#### What is Healine?

Healine is an open-source platform that provides a unified API for accessing health data from multiple wearable devices and fitness platforms. It supports providers like Garmin, Fitbit, Oura, Whoop, Strava, and Apple Health.

#### Is Healine free to use?

Yes, Healine is open-source and free to use. You can self-host it on your own infrastructure.

#### Can I use Healine for personal use?

Healine is primarily intended for developers and professional trainers, but individuals can also use it to interact with their own wearable data. You can connect supported devices and explore their data through the developer portal, REST API, and MCP server.

### Technical Questions

#### How do I get started?

Follow our [Quickstart Guide](/quickstart) to set up Healine in minutes.

#### Which wearable providers are supported?

Healine supports a growing list of providers.

**Cloud-based (OAuth):** Oura, Whoop, Strava, Fitbit, Ultrahuman, Polar, Suunto, Garmin, and Google Health.

**SDK-based:** Apple Health, Google Health Connect, and Samsung Health.

More providers are being added regularly. See the [supported providers guide](/providers/supported) for the full list and per-provider setup instructions, the [coverage matrix](/providers/coverage) for exactly which data types each provider exposes, or upstream provider requests on [Open Wearables issues](https://github.com/the-momentum/open-wearables/issues?q=is%3Aissue+label%3Aprovider-request) tagged with `provider-request`.

#### Can I self-host Healine?

Yes! Healine is designed to be self-hosted. You can deploy it on your own infrastructure with full data control.

#### How can I deploy Healine?

Build and run the fork from source using the [Docker guide](/deployment/docker). It includes the backend, developer portal, database, and background workers. Published Healine images and a Healine Railway template are not provided yet.

#### How do I integrate Healine into my application?

You can integrate Healine using:
- The unified REST API
- [Webhook notifications](/api-reference/guides/webhooks) for real-time updates (e.g. `connection.created`, new data events)

Check the [API Reference](/api-reference/introduction) for detailed integration guides.
